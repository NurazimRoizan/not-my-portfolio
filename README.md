# ⚠️ UNHANDLED EXCEPTION: CREATIVE PORTFOLIO

Welcome to the void. This isn't a clean, minimalist corporate portfolio built on a template. 
This is a brutalist, unhinged, mobile-first evidence board of my technical capabilities.

## 💀 THE TECH STACK
Built with spite and raw power:
- **React + Vite** (Because we don't have time to wait for Webpack)
- **Vanilla CSS** (No Tailwind. We write our own brutal keyframes here)
- **GSAP ScrollTrigger** (For neon SVG paths that violently draw themselves)

## 🩸 DESIGN SYSTEM: NEO-BRUTALISM
This portfolio violates standard design conventions on purpose:
- **Colors:** Blackboard Void (`#111111`), Piercing Cyan (`#00ffff`), Screaming Hot Pink (`#ff00ff`), Hazard Yellow (`#ffff00`)
- **Styling:** Thick solid borders, hard 0px drop-shadow offsets, and screaming caps-lock typography. 
- **Micro-interactions:** Elements don't just sit there. They violently shake and vibrate when you hover over them.

## 🚀 LAUNCH SECUENCE
To run this beast locally and watch the SVGs assault your eyes:

```bash
# Install the dependencies
npm install

# Ignite the dev server
npm run dev
```

## 📂 THE ARCHITECTURE
- **Phase 1:** Core structure, components, and brutalist CSS engine.
- **Phase 2:** The Chaos Layer. Absolutely positioned SVG arrows that act as a demonic GPS, pointing you down the page using `strokeDashoffset` scroll animations.
